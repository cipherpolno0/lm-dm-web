**เฟส:** P0 — Orientation & Safety
**อ้างอิงคู่กับ:** `project-charter.md`, `requirements.md`, `data-policy.md`, `dev-rules.md`, `user-flows.md`
**สถานะ:** ร่างสำหรับ Owner Review
**เวอร์ชัน:** 0.1 | **วันที่:** 2026-09-14

> เอกสารนี้ใช้ข้อมูลสมมติเท่านั้น ไม่มีชื่อบุคคล วัด หรือหน่วยงานจริงปรากฏอยู่ ชื่อ path/หน้าจอทั้งหมดเป็นข้อเสนอเบื้องต้น รอ Owner ยืนยัน

## 1. วัตถุประสงค์

กำหนดโครงสร้างหน้าเว็บ (sitemap) ของระบบ แบ่งเป็น 3 โซนตามระดับการเข้าถึง: **Public**, **Member**, **Admin (หลังบ้าน)** เพื่อใช้เป็นฐานสำหรับออกแบบ route ใน Next.js App Router และผูกกับ Actor/Permission ที่กำหนดไว้ใน `requirements.md` ข้อ 3 และข้อ 6

## 2. แนวทาง Route Group (Next.js App Router)

| Route Group | โซน | การยืนยันตัวตน | หมายเหตุ |
|---|---|---|---|
| `app/(public)/...` | Public | ไม่ต้องล็อกอิน | เข้าถึงได้โดยทุกคน |
| `app/(member)/...` | Member | ต้องล็อกอิน | Middleware ตรวจ session ก่อนเข้า, เนื้อหาภายในปรับตามบทบาท (role-aware rendering) แต่ **การตรวจสิทธิ์จริงต้องทำซ้ำฝั่ง server ในแต่ละ route/action เสมอ** ตาม `dev-rules.md` ข้อ 4 — ห้ามพึ่ง route group เพียงอย่างเดียว |
| `app/(admin)/...` | Admin (หลังบ้าน) | ต้องล็อกอินและมีบทบาทที่กำหนด | เฉพาะ Super Admin / Central Officer (บางส่วน) / Auditor (อ่านอย่างเดียว) |

หน้า error (403/404/500) และหน้า maintenance อยู่นอก 3 กลุ่มนี้ ใช้ร่วมกันทุกโซน (ดูข้อ 6)

| `/curriculum/[track]` | รายละเอียดสายการศึกษา | ระดับชั้นของแต่ละสาย (เช่น ตรี/โท/เอก, ประโยค 1–9) | Guest | `track` = นักธรรม \| ธรรมศึกษา \| บาลี |

| `/register` | สมัครสมาชิก | จุดเริ่มต้น Flow สมัครสมาชิก | Guest | เชื่อมกับ Flow สมัครสมาชิก |

| `/privacy`, `/terms` | นโยบายความเป็นส่วนตัว/ข้อกำหนดการใช้งาน | หน้าคงที่ | Guest | เนื้อหาต้องรอ policy จริงจากองค์กร |
| `/contact` | ติดต่อเรา | ช่องทางติดต่อ | Guest | ไม่บังคับ — รอยืนยันความจำเป็น |

## 4. Member Zone (ต้องล็อกอิน)

เนื้อหาในโซนนี้ปรับตามบทบาท (role-aware) โดยยึด scope ตามลำดับชั้นการปกครองสำหรับ Regional Admin/Registrar Staff เสมอ (ดู `requirements.md` ข้อ 6)

### 4.1 หน้าใช้ร่วมกันทุกบทบาทใน Member

| Path | หน้า | วัตถุประสงค์ | Actor |
|---|---|---|---|
| `/dashboard` | แดชบอร์ดหลัก | ภาพรวมงาน/ทางลัดตามบทบาท | ทุกบทบาทใน Member |
| `/profile` | โปรไฟล์ของฉัน | ดู/แก้ไขข้อมูลส่วนตัวของตนเองภายในขอบเขตที่อนุญาต | ทุกบทบาทใน Member |
| `/profile/security` | ความปลอดภัยบัญชี | เปลี่ยนรหัสผ่าน, ดู session ที่ใช้งาน | ทุกบทบาทใน Member |

### 4.2 Student (นักเรียน/ผู้เข้าสอบ)

| Path | หน้า | วัตถุประสงค์ |
|---|---|---|
| `/my/exams` | สมัครสอบ | ลงทะเบียนสอบตามระดับชั้นที่มีสิทธิ์ |
| `/my/quiz` | แบบฝึกหัด/Quiz | ทำแบบฝึกหัดออนไลน์จากคลังข้อสอบที่เปิดให้ฝึก |
| `/my/results` | ผลสอบของฉัน | ดูผลสอบย้อนหลังทั้งหมดของตนเอง |
| `/my/documents` | เอกสาร/ใบประกาศนียบัตรของฉัน | ดาวน์โหลดเอกสารของตนเอง |

### 4.3 Teacher (ครูสอนธรรม/ครูสอนบาลี)

| Path | หน้า | วัตถุประสงค์ |
|---|---|---|
| `/teach/questions` | ข้อสอบที่เสนอ/ทบทวน | เสนอข้อสอบใหม่เข้าคลัง หรือทบทวนที่เสนอไปแล้ว |
| `/teach/students` | นักเรียนในความรับผิดชอบ | ติดตามความคืบหน้า/ผลของนักเรียนที่ตนสอน |

### 4.4 Examiner (ผู้ตรวจข้อสอบ/กรรมการคุมสอบ)

| Path | หน้า | วัตถุประสงค์ |
|---|---|---|
| `/examine/sessions` | รอบสอบที่ได้รับมอบหมาย | ดูรายชื่อรอบสอบที่ตนรับผิดชอบ |
| `/examine/sessions/[id]/scores` | บันทึกคะแนน | กรอก/แก้ไขคะแนนของรอบสอบนั้น |

### 4.5 Registrar Staff (เจ้าหน้าที่ธุรการสำนักเรียน/วัด)

| Path | หน้า | วัตถุประสงค์ |
|---|---|---|
| `/registry/members` | ทะเบียนพระภิกษุ/สามเณร (เฉพาะสังกัด) | ดู/เพิ่ม/แก้ไขข้อมูลทะเบียนในสังกัดตน |
| `/registry/students` | ทะเบียนนักเรียน (เฉพาะสังกัด) | จัดการรายชื่อนักเรียนในสังกัดตน |
| `/registry/import` | นำเข้าข้อมูล Excel (เฉพาะสังกัด) | Import แบบ batch พร้อม dry-run/validation |

### 4.6 Regional Admin (ผู้บริหารคณะสงฆ์ระดับภาค/จังหวัด/อำเภอ/ตำบล)

| Path | หน้า | วัตถุประสงค์ |
|---|---|---|
| `/region/overview` | ภาพรวมเขตปกครอง | สรุปข้อมูลทะเบียน/ผลสอบในเขตตนและเขตย่อย |
| `/region/registry` | ทะเบียนในเขตปกครอง | จัดการทะเบียนทั้งเขต (กว้างกว่า Registrar Staff) |
| `/region/exam-centers` | สนามสอบในเขต | จัดการ/ดูสนามสอบที่อยู่ในเขตตน |
| `/region/reports` | รายงานเฉพาะเขต | ดาวน์โหลด/ดูรายงานสรุปเฉพาะเขตปกครองของตน |

### 4.7 Central Officer (เจ้าหน้าที่ส่วนกลาง)

Central Officer ใช้ทั้งหน้าที่ใช้ร่วม (4.1) และหน้าจอเฉพาะใน **Admin Zone** สำหรับงานที่เป็นการตั้งค่าระดับระบบ (ดูข้อ 5.2) ไม่มีหน้าจอเฉพาะเพิ่มเติมใน Member Zone

## 8. Non-goals ที่สะท้อนใน Sitemap

ตาม `project-charter.md` ข้อ 4: ไม่มีหน้า public API, ไม่มีหน้าชำระเงิน/บริจาค, ไม่มีแอปมือถือแยก (เว็บ responsive เท่านั้นในเฟสนี้)

## 9. ข้อสมมติ/ประเด็นที่ต้องยืนยันกับ Owner

- [ ] `/exam-results/lookup` (ตรวจสอบผลสอบสาธารณะ) — **ยังไม่ยืนยันว่าจะเปิดให้บริการหรือไม่** เพราะมีความเสี่ยงด้านความเป็นส่วนตัวเมื่อใช้ข้อมูลจริง ต้องออกแบบให้ค้นหาได้เฉพาะด้วยเลขอ้างอิงที่ผู้ขอสอบทราบเท่านั้น ห้ามค้นหาด้วยชื่อหรือแสดงรายชื่อทั้งหมด และต้องผ่าน Real-data Readiness Gate ก่อนใช้ข้อมูลจริง
- [ ] ชื่อ path และการจัดกลุ่มเมนูเป็นข้อเสนอเบื้องต้น — รอ Owner/ผู้ใช้งานจริงยืนยันคำศัพท์และลำดับความสำคัญของเมนู
- [ ] จำนวนระดับชั้นการปกครอง (ภาค/จังหวัด/อำเภอ/ตำบล) ที่ใช้จริงยังรอยืนยัน (dependency เดิมจาก `project-charter.md` ข้อ 8) มีผลต่อจำนวนหน้า Regional Admin

## 10. เงื่อนไขการตรวจรับเอกสารนี้

- [ ] Owner ยืนยันโครงสร้าง 3 โซนและรายการหน้าจอครบถ้วนตามความต้องการจริง
- [ ] Owner ตัดสินใจเรื่อง `/exam-results/lookup` (ข้อ 9)
- [ ] ยืนยันว่าเอกสารนี้ไม่มีข้อมูลบุคคล/หน่วยงานจริงปรากฏ
